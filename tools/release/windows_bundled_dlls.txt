# Third-party DLLs bundled into build/dll/ of the windows-x64 release zip (#200).
#
# Only DLLs the gnustep-cli toolchain does not ship. A DLL's own imports must be
# bundled here, present in that toolchain's clang64/bin, or Windows system DLLs;
# package_framework.sh checks this and fails otherwise.
#
# One section per toolchain. A `toolchain` line starts a section, and the zip
# bundles the `dll` lines of the section whose version AND artifact sha256 match
# the toolchain it is built against (state/cli-state.json). A build against any
# other toolchain fails until a section for it is added: derive the packages
# from the package set that toolchain was locked against, and check the DLLs'
# imports against that toolchain's own DLLs.
#
# toolchain <toolchain_version> <toolchain_artifact_sha256>
# dll <package_url> <package_sha256> <member> <member_sha256>
